# Images

Drop image files here as you build out each page. Suggested names to match
upcoming markup:

- `hero-space.jpg` — wide shot of the main floor (optional, hero is currently CSS-only)
- `space-hotdesk.jpg`, `space-studio.jpg`, `space-meeting.jpg` — for spaces.html
- `about-team.jpg`, `about-interior.jpg` — for about.html
- `og-image.jpg` — social share preview image (1200x630)

Keep file sizes reasonable (under ~300KB) and use `.jpg` for photos,
`.svg` for icons/logos where possible.
